# 提花编织口令校验（Jacquard RLE Checker）

在定宽符号网格中绘制提花图案，系统按实际编织方向（奇数行 → 自左向右、偶数行 ← 自右向左）生成逐行游程（RLE）口令；也可以直接编辑口令并校验回写——**仅当某行游程针数之和恰好等于行宽时才回写该行**，否则保留原图并定位错误。网格与口令来回切换时，**偶数行始终保持视觉坐标、绝不镜像**。网格编辑页内置**浮线风险检查**：逐行找出被同色针脚夹住、跨针数超过阈值的浮线区间，实时标注起止列与颜色；并内置**循环花版**面板：搜索可平铺生成整幅图案的最小二维重复单元，显示单元尺寸与压缩比、在原网格描出单元边界，支持行/列偏移与 3×3 平铺预览；还内置**备纱配筒**面板：按当前网格各符号针数与克/1000针、损耗率计算用纱需求（向上取到 0.1 克），从录入的纱筒中为每种符号精确选出可覆盖需求的子集（依次最小化启用筒数、超出克重、编号序列），库存不足时如实显示缺口与全部可用量。「图案网格」与「游程口令」之间另有**对版**模式：把口令编辑区中的候选口令解析为临时图案（**不回写当前网格**），与当前网格逐格按视觉坐标比较，在网格上叠加标出新增纹样、缺失纹样与颜色替换，侧栏按行汇总差异数量，点击条目即可定位该行首个差异。对版页内置**错位对齐搜索**：将可比较的候选图案按视觉坐标在行、列方向循环平移，枚举用户限定的最大偏移，按差异格总数选出最佳方案（针数错误或缺失行不参与评分），侧栏同时显示原始与最佳差异数及偏移，支持一键切换最佳对齐预览。

## 单条命令启动

```bash
docker compose up -d --build
```

启动后访问：

- **应用地址：http://localhost:8080**
- **对版入口：http://localhost:8080 → 顶部「对版」页**（先在「游程口令」页编辑候选口令，对版只读比较、不回写网格，无需额外服务或端口）
- **循环花版入口：http://localhost:8080 →「图案网格」页 → 网格下方「循环花版」面板**（与浮线风险检查面板并列，无需额外服务或端口）
- **备纱配筒入口：http://localhost:8080 →「图案网格」页 →「循环花版」面板下方「备纱配筒」面板**（无需额外服务或端口，配置保存在浏览器本地）

依赖安装、前端构建、服务启动均在镜像构建时自动完成，无需本机 Node 环境。

停止：

```bash
docker compose down
```

> 端口可在 `docker-compose.yml` 的 `ports` 中修改（如 `"9000:8080"`）。

## 使用方法

1. 工具栏设置 **行宽（针数）** 与 **行数**，选择符号 A / B / C（默认 A 为底）。
2. 在网格上点击或拖动绘制；行首箭头标示该行实际编织方向（奇 → / 偶 ←），列号恒为视觉坐标。
3. 点击 **生成逐行口令**，得到形如：

   ```text
   01 → B2 A4 B2
   02 ← B2 A4 B2
   03 → A3 B2 C2 A1
   04 ← A1 C2 B2 A3
   ```

   注意第 4 行与第 3 行视觉内容相同，但口令顺序相反——偶数行从网格最右端开始读，回写后图案不变。
4. 切换到 **游程口令** 页可直接编辑，点击 **校验并回写网格**：
   - 针数恰好等于行宽的行：回写网格；
   - 针数多/少、符号未启用、片段无法识别、行号重复/越界的行：**整行保留原图**，错误出现在下方清单中，点击条目即定位到口令对应行，网格中该行以红框标出；
   - 偶数行针数不足时，缺口按编织方向定位到视觉左侧；溢出时定位越过最左/右边界的游程。
5. 网格编辑页下方的 **浮线风险检查** 面板可设置 **最大浮线针数（3～12，默认 5）**：
   - 逐行分析每种颜色相邻两次落针之间跨过的其他针数；**只有被同色针脚两端夹住的区间计为浮线**，行首/行尾的开放区间不计；
   - 超过阈值的浮线在网格中以红色下划线标出区间、起止列描边，并按视觉坐标汇总为风险列表，点击条目即定位对应行列；
   - 绘制、改尺寸、改阈值或口令回写后结果实时重算；风险位置恒为视觉坐标，**不随偶数行镜像**。
6. 浮线面板下方的 **循环花版** 面板实时给出当前图案的最小二维重复单元：
   - 显示 **单元尺寸（行 × 列）与压缩比**（整幅格数 ÷ 单元格数），并在原网格上以紫色描出单元边界线；
   - 提供 **行偏移 / 列偏移** 控制（视觉坐标相位，0～周期-1 循环）与 **3×3 平铺预览**，中心描出的即当前相位的一个完整单元；
   - 绘制、改尺寸或口令回写后立即重算，偏移与预览同步更新。
7. 循环花版面板下方的 **备纱配筒** 面板按当前网格实时配筒：
   - 为 A / B / C 分别设置 **克/1000针** 与 **损耗率（0～30%）**，并录入纱筒（**唯一编号 + 可用克重**，全部符号合计最多 **20 个**）；
   - 每种符号的需求 = 针数 × 克/1000针 ÷ 1000 ×（1＋损耗率），**向上取到 0.1 克**；
   - 系统从该符号自己的纱筒中**精确选筒**：依次最小化启用筒数、超出克重、编号序列；库存不足时不生成伪可行组合，如实显示缺口与全部可用量；
   - 绘制、改尺寸或口令回写后立即重算；配置自动保存在浏览器本地。
8. 顶部 **对版** 页把「游程口令」编辑区中的文本当作候选口令，与当前网格逐格比对（详见下节）。

## 对版（候选口令比对）

- **入口**：顶部「对版」页（位于「图案网格」与「游程口令」之间）。候选口令即「游程口令」编辑区中的文本，可先在口令页编辑或由网格生成后改写。
- **只读比较**：候选口令被解析为临时图案，**绝不回写当前网格**；对版页网格为只读。
- **逐格视觉坐标比较**：候选行仍按实际编织方向落针（偶数行 ← 自右向左解码），随后完全在视觉坐标上逐格比较——**差异列号绝不随偶数行镜像**。
- **差异分类（以 A 为底色）**：
  - **新增纹样**（绿框）：候选织入非底色符号，当前网格该格为底色 A；
  - **缺失纹样**（红框）：当前网格有纹样，候选该格回到底色 A；
  - **颜色替换**（橙框）：两侧均为非底色但符号不同；差异格右上角角标显示候选符号。
- **侧栏按行汇总**：每行列出新增/缺失/替换数量与首个差异列；**点击条目即定位该行首个差异**（网格滚动并高亮）；完全一致的行标记“与候选一致”。
- **不可比较行**：针数错误（多/少针）或无法解析的候选行整行标记为不可比较，**绝不用部分落针结果参与该行差异**；没有候选口令的行同样不可比较。行号冲突/越界的候选行在侧栏底部单独列出。
- **错位对齐搜索**：侧栏「错位对齐」区块可设置 **最大偏移（0～8，默认 3）**，将可比较的候选图案按视觉坐标在行、列方向做循环平移，枚举 ±最大偏移 内全部偏移方案，按差异格总数选出最佳：
  - **针数错误或缺失行不参与评分**——它们不产生差异格，每个方案的被评分格数恒为 可比较行数 × 行宽；
  - 侧栏同时显示 **原始差异数（偏移 0,0）与最佳差异数及其行/列偏移**；
  - 同分时依次按 **偏移曼哈顿距离 → 行偏移绝对值 → 列偏移绝对值 → 带符号行偏移 → 带符号列偏移** 稳定决胜，结果唯一确定；
  - 最佳方案严格更优时，点击 **预览最佳对齐** 一键切换：网格差异与行汇总立即按最佳偏移重算（候选图案层整体循环平移，偶数行视觉坐标保持原位），再次点击返回原始对版；
  - 候选口令、当前网格或最大偏移任一变化，搜索结果实时重算。
- **实时重算**：候选文本或当前网格任一变化，对版结果立即重新计算；点击侧栏 **清除对版** 可一键清空当前对版标记（再次修改候选或网格后自动恢复，也可手动“重新对版”）。

## 循环花版（最小重复单元）

- **定义**：最小的 `行数 × 列数` 单元，使得整幅图案的每一格 `(r, c)` 都等于单元内坐标 `(r mod 行数, c mod 列数)` 处的符号——即该单元按二维平铺可完整生成当前图案。
- **搜索与决胜**：候选周期 **不要求整除行宽或行数**（边界处允许残缺单元）；按 **面积 → 行数 → 列数** 升序枚举，第一个通过验证的候选即为结果。
- **逐格验证**：每个候选都按单元内坐标映射 **逐格** 与整幅比对，而不是只比较首个完整块——例如 5 行图案的前 4 行呈周期 2、第 5 行破坏周期时，绝不会误判为 2 行单元。
- **压缩比** = 整幅格数 ÷ 单元格数；单元等于整幅时提示“无更小重复单元”（压缩比 1:1）。
- **边界描线**：原网格上按当前偏移相位以紫色描出每个单元（含边缘残缺单元）的边界，网格外缘自动闭合。
- **偏移与预览**：行/列偏移只是单元内容的 **视觉坐标相位平移**（取模循环），3×3 平铺预览随之更新；与全站约定一致，**偶数行绝不镜像**。
- **实时重算**：搜索为纯函数，绘制、修改行宽/行数、口令校验回写（合法行覆盖、错误行保留原图）后立即重新搜索。

## 备纱配筒

- **需求计算**：每种符号的需求 = 该符号在当前网格中的针数 × 克/1000针 ÷ 1000 ×（1＋损耗率），**向上取到 0.1 克**。损耗率限 0～30%。全部克重运算在 0.1 克整数刻度上进行，浮点噪声不会把恰好落在刻度上的需求向上顶一格（如 1000 针 × 0.3 克/1000针 恰为 0.3 克）。
- **纱筒录入**：每个纱筒有**唯一编号**（跨全部符号不可重复）与**可用克重**（0.1 克精度），并归属某个符号；全部符号合计最多 **20 个**。只有同符号的纱筒参与该符号的配筒。
- **精确选筒**：对每种符号，从该符号的纱筒中选出合计克重 ≥ 需求的子集，依次最小化：
  1. **启用筒数**；
  2. **超出克重**（选中筒合计 − 需求）；
  3. **编号序列**（选中筒编号升序排列后的字典序，保证结果唯一确定，与录入顺序无关）。
  求解为子集和动态规划精确搜索，**不是逐筒贪心近似**——贪心“从大到小逐筒加入”在超出克重上可能不是最优（如需求 10、筒 [6, 5, 5]，贪心得 6+5=11，最优为 5+5=10）。
- **库存不足**：该符号全部纱筒合计仍小于需求时，**不生成伪可行组合**，面板如实显示 **缺口（需求 − 全部可用量）与全部可用量**；需求为 0 时不启用任何筒。
- **面板展示**：逐符号显示针数、需求（克）、选中筒编号（列表中同步标记“选中”）、余量；库存不足时改显缺口与全部可用量。
- **实时重算**：绘制、修改行宽/行数、口令校验回写（合法行覆盖、错误行保留原图）或编辑配筒参数后，需求与选筒结果立即重新计算。
- **本地保存**：克/1000针、损耗率与纱筒清单自动保存在浏览器 localStorage，刷新后恢复。

## 口令格式

- 每行对应一个图案行；格式为 `符号+针数`，空白/逗号分隔，如 `A4 B2 A2`；相邻游程也允许不写分隔，如 `A4B2A2`。
- 可省略行号与箭头：省略行号时第 n 条口令对应图案第 n 行（空行不参与编号；显式行号重排不影响其他隐式行的对应关系）。
- 可写显式行号：`02 ← A2 B4 A2`、`2: A2B4A2`、`2行 A2 B4` 均可（`:`、`：`、`.` 为可选分隔）。
- 方向箭头 `→ ← -> <- > <` 仅作标注，会被自动忽略；`#` 之后为注释。
- 符号大小写不敏感（内部统一转大写）。
- **校验规则：每行针数之和必须恰好等于行宽**，不多一针也不少一针。

## 本地开发（不使用 Docker）

要求 Node.js ≥ 20。

```bash
npm install        # 安装全部 workspace 依赖
npm run dev        # 并行启动：shared 监听构建、:8080 API、:5173 前端（自动代理 /api）
```

- 前端（Vite HMR）：http://localhost:5173
- API 服务：http://localhost:8080

生产构建与本地运行：

```bash
npm run build      # 依次构建 shared → server → client
npm start          # Node 服务托管前端与 API：http://localhost:8080
```

运行核心编解码测试：

```bash
npm run build -w packages/shared && npm test
```

## HTTP API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/encode` | `{ grid, width, height }` → 逐行游程口令（偶数行按 ← 读取） |
| `POST` | `/api/decode` | `{ text, width, height, fallback, symbols }` → `{ grid, issues, appliedRows, ok }`；非法行取 `fallback` 原图 |

## 编织方向与不镜像约定

| 行 | 实际编织方向 | 口令读取顺序 | 网格视觉 |
| --- | --- | --- | --- |
| 奇数行（1、3、5…） | → | 视觉列 1 → N | 正常 |
| 偶数行（2、4、6…） | ← | 视觉列 N → 1（第一个游程在最右端） | **位置不变，不翻转** |

因此同一段视觉图案在偶数行的口令与相邻奇数行顺序相反；解析回写时同样从偶数行最右端落针，保证往返一致。

## 浮线风险检查

- **浮线定义**：同一行内，某种颜色相邻两次落针之间跨过的其他颜色针数。只有**被同色针脚两端夹住**的区间才计为浮线；行首/行尾的开放区间（该颜色首次出现之前、最后一次出现之后）不计。
- **阈值**：最大浮线针数可选 3～12，默认 5；浮线长度**严格大于**阈值才计为风险。
- **标注**：超阈值浮线在网格上以红色下划线标出整个区间，起止列（两端同色针脚）描边；风险列表按视觉坐标（行 → 起始列）汇总，点击条目高亮并滚动定位到对应行列。
- **不镜像**：浮线分析完全基于视觉坐标，奇偶行只影响口令阅读顺序，偶数行的风险位置绝不翻转。
- **实时重算**：绘制图案、修改行宽/行数、调整阈值，或口令校验回写（合法行覆盖、错误行保留原图）后，检查结果立即更新。
